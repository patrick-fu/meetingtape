# MeetingTape：GUI 原型

在项目目录执行：

```sh
python3 Prototypes/GUI/serve.py
```

打开 [融合方案](http://127.0.0.1:8765/?variant=F)。底部保留最初五套方案供比较，左右方向键也可切换；正在编辑输入框时保留其正常光标操作。

融合版把 A 的资料库与独立录音悬浮窗组合起来，参考用户提供的豆包截图：

- 从资料库开始录音，默认出现仅含时间、波形、停止与展开按钮的悬浮条。
- 展开可编辑正在录制的标题、查看音源状态；拖动悬浮窗可以调整位置。
- 录制时仍能浏览和整理已有录音；关闭资料库后，悬浮窗继续录制。
- 停止后自动入库，悬浮窗消失；资料库关闭时保持关闭，通过保存提示或“打开资料库”回看。

这里的窗口独立性和录制是浏览器内的交互演示。系统全局置顶、跨桌面与全屏应用显示、焦点行为仍需在 macOS 正式窗口中实现并验收。

| 方案 | 体验 |
| --- | --- |
| [F 融合方案](http://127.0.0.1:8765/?variant=F) | 资料库负责整理，极简悬浮窗负责录制，可展开、收起和拖动 |
| [A 资料库](http://127.0.0.1:8765/?variant=A) | 双栏主窗口，录音列表、波形与详情 |
| [B 菜单栏](http://127.0.0.1:8765/?variant=B) | 右上角轻量面板，录音时可收起 |
| [C 录音机](http://127.0.0.1:8765/?variant=C) | 实体设备式双表头、机械按钮与磁带抽屉 |
| [D 启动器](http://127.0.0.1:8765/?variant=D) | 搜索、上下键与 Enter；录音中可收成浮层 |
| [E 伴随条](http://127.0.0.1:8765/?variant=E) | 可拖动、可收起的会议悬浮控件 |

每套都能操作开始、计时、停止、最近录音与试听，并配置名称、输出位置和原麦保留。录音流程和文件列表使用内存演示数据，切换方案或刷新后重置；试听与导出使用仓库内的十秒双声道 AAC 示例。示例由本地合成，不含真实会议内容。

这些是用于选择界面方向的浏览器原型。真实音频引擎的 AEC 未通过项仍保留在 [验收记录](../../docs/local-verification.md)，界面中的演示状态不代表其验收结果。

产品形态参考与约束见 [BRIEF.md](BRIEF.md)。原型保存在 `p/patrick/gui-prototypes` 分支；选定方向后再实现正式 GUI。

# MeetingTape：GUI 原型

在项目目录执行：

```sh
python3 Prototypes/GUI/serve.py
```

打开 [融合方案](http://127.0.0.1:8765/?variant=F)。底部保留最初五套方案供比较，左右方向键也可切换；正在编辑输入框时保留其正常光标操作。

融合版把 A 的资料库与独立录音悬浮窗组合起来，参考用户提供的豆包截图：

- 从资料库开始录音，默认出现仅含时间、波形、停止与展开按钮的悬浮条。
- 展开可编辑正在录制的标题、查看音源状态；拖动悬浮窗可以调整位置。
- 录制时仍能浏览和整理已有录音；关闭资料库后，悬浮窗继续录制。
- 停止后自动入库，悬浮窗消失；资料库关闭时保持关闭，通过保存提示或“打开资料库”回看。

这里的窗口独立性和录制是浏览器内的交互演示。系统全局置顶、跨桌面与全屏应用显示、焦点行为仍需在 macOS 正式窗口中实现并验收。

| 方案 | 体验 |
| --- | --- |
| [F 融合方案](http://127.0.0.1:8765/?variant=F) | 资料库负责整理，极简悬浮窗负责录制，可展开、收起和拖动 |
| [A 资料库](http://127.0.0.1:8765/?variant=A) | 双栏主窗口，录音列表、波形与详情 |
| [B 菜单栏](http://127.0.0.1:8765/?variant=B) | 右上角轻量面板，录音时可收起 |
| [C 录音机](http://127.0.0.1:8765/?variant=C) | 实体设备式双表头、机械按钮与磁带抽屉 |
| [D 启动器](http://127.0.0.1:8765/?variant=D) | 搜索、上下键与 Enter；录音中可收成浮层 |
| [E 伴随条](http://127.0.0.1:8765/?variant=E) | 可拖动、可收起的会议悬浮控件 |

每套都能操作开始、计时、停止、最近录音与试听，并配置名称、输出位置和原麦保留。录音流程和文件列表使用内存演示数据，切换方案或刷新后重置；试听与导出使用仓库内的十秒双声道 AAC 示例。示例由本地合成，不含真实会议内容。

这些是用于选择界面方向的浏览器原型。真实音频引擎的 AEC 未通过项仍保留在 [验收记录](../../docs/local-verification.md)，界面中的演示状态不代表其验收结果。

产品形态参考与约束见 [BRIEF.md](BRIEF.md)。原型保存在 `p/patrick/gui-prototypes` 分支；选定方向后再实现正式 GUI。

## 实时字幕：大小窗形态探索

同一启动命令下打开 [字幕原型](http://127.0.0.1:8765/?study=captions&variant=A)。底部只在三个字幕方案间切换，原 A–F 录音形态保留原链接。字幕原型代码位于 `captions.html`，是独立的可丢弃演示。

| 方案 | 小窗 | 大窗 |
| --- | --- | --- |
| [A 轻字幕条](http://127.0.0.1:8765/?study=captions&variant=A) | 196×54 横条，保留一行当前字幕与置顶开关 | 380×320 时间顺序阅读，历史和当前句同一条时间线 |
| [B 两行字幕卡](http://127.0.0.1:8765/?study=captions&variant=B) | 348×196 卡片，最多两行当前字幕 | 420×546，历史弱化，当前发言大字聚焦 |
| [C 双音源字幕](http://127.0.0.1:8765/?study=captions&variant=C) | 680×143 底部字幕条，两路音源各占一行 | 438×565 侧窗，按麦克风 / 系统音频筛选 |

尺寸是宽屏下的 CSS 像素，较小视口会适配。每种小窗和大窗都显示字幕，可展开/收起、拖动、停止、回看历史并回到最新；关闭资料库后字幕窗继续。右上角可重播、暂停演示，并切换自然对话、长句修正与模拟断网。停止后演示结果保存到内存资料库，重新开始重置样本。

这里只模拟文字输入与录音状态，不采集麦克风、不调用模型、不上传音频、不持久化。网络中断仅为页面内模拟，不改变宿主机网络。音源标签也是演示数据，不代表当前实时模型已能稳定区分两路声音。浏览器内拖动及层叠不证明系统置顶、跨 Space 或焦点行为。实时链路接入与原有 AEC 未通过结论保持独立。

用户已选择 A，并要求进一步缩小、支持取消置顶。A 的大小窗均有 pin，默认置顶，展开收起保留选择。取消置顶后，点击资料库可将它移到字幕窗前；演示控制中的“显示字幕窗”可将字幕窗唤回。重新置顶后，点击资料库不会遮挡字幕。这里只演示浏览器层级，实际系统窗口行为仍待原生实现与验收。

A 小窗按整体比例调整为 196×54：字幕 11px、计时 9px、按钮 20px，波形最高约 10px；去掉控件间分隔线并减轻阴影。字幕保留末尾 14 字，展开后继续完整阅读。

# MeetingTape GUI 形态探索

问题：同样的本地双源录音任务，哪种桌面入口和信息结构最顺手？最初五套可交互高保真原型通过 `?variant=A` 至 `E` 比较；用户随后给出 A 资料库加极简悬浮窗的收敛方向，新增 `?variant=F` 验证两个窗口各自分工。该段是首次探索时的历史记录，原生 GUI 已在独立生产分支实现。

## 融合方向

依据本次用户提供的两张豆包截图：收起态仅保留时间、波形、停止、展开；展开态提供标题编辑、较大波形与音源状态。资料库负责浏览、命名、标记、搜索和回听已有录音。开始录音后默认收起，关闭资料库不终止录音，停止后自动入库。保存时保持资料库原本的开关状态，通过保存提示中的“查看录音”主动返回。

浏览器已用于验证这些交互关系；原生全局置顶、跨 Space、全屏应用和不抢焦点仍是 macOS 实装的验收项。当前音源指示和波形均为演示，不表示 AEC 验收通过。截图中的转写与暂停不属于现有录音引擎能力，融合原型继续沿用开始、停止的边界。

## 最初五套参考

这是浏览器中的桌面界面原型。所有录音状态与列表只存在内存，操作使用演示数据；试听与导出提供本地生成的双声道 AAC 示例。保留真实引擎的边界：录音只有开始、停止；系统音频与麦克风分别记录；可保留原始麦克风；有输出位置；没有转写、AI 摘要、云账户和公开的录音暂停功能。

| 方案 | 结构与气质 | 参考入口 |
| --- | --- | --- |
| A 资料库 | macOS 双栏资料库，大幅波形与录音详情，轻灰与冷蓝 | [语音备忘录 Mac](https://support.apple.com/guide/voice-memos/welcome/mac) |
| B 菜单栏 | 桌面右上角的小型下拉面板，快捷开始与最近录音 | [CleanShot](https://cleanshot.com/) |
| C 录音机 | 暖色实体设备，双 VU 表、机械按钮与计时显示 | [Piezo](https://rogueamoeba.com/piezo/) |
| D 启动器 | 深色命令面板，以搜索、键盘和动作列表组织录音 | [Raycast](https://manual.raycast.com/search-bar) |
| E 伴随条 | 会议场景中的轻量悬浮控件，可展开来源与最近录音 | [Superwhisper](https://superwhisper.com/) 的全局快捷入口与浮层形态 |

只参考产品形态，不复刻品牌素材。根目录的 `index.html`、`bridge.js` 和 `serve.py` 由主 agent 拥有；每个变体独立布局，不共享页面模板。

初始变体文件 `variants/a.html` 至 `e.html` 与融合版 `f.html` 使用原生 HTML/CSS/JS，无外部依赖。页面载入 `../bridge.js`，每次操作后调用 `window.reportState({ variant: 'A', status: 'ready', ... })`。桥接脚本将状态提供给外层原型控制器，不在产品界面显示调试信息。示例音频位于 `../assets/sample-stereo.m4a`。

以 1440×900 和 1280×800 为主要桌面视口；为外层左上角原型标识和底部切换器留出空间。所有可见按钮和输入都应响应操作，至少能完成开始、计时、停止、保存到列表与试听，以及标题、输出位置、保留原麦设置。正常文案简短，使用中文；图标用 SVG 或 CSS。形态差异应体现在窗口结构和操作路径，而非仅换色。

## 2026-10-26：大小窗都显示实时字幕

用户明确修正：小窗和大窗都应该显示字幕。新增同一入口 `?study=captions&variant=A/B/C`，不覆盖原来的 A–F 历史原型。三个方向分别改变小窗信息密度与展开后的阅读结构：横向一行、两行聚焦、双音源并列。

实时能力调研已完成豆包 2.0 合成音频接口探测，但本轮只评估 UX。原型文字模拟生成，不调用真实麦克风或云服务；断网也只模拟字幕状态，不修改宿主网络。生产转写接入位于 PR #14，未将浏览器原型混入生产代码。

小窗与大窗共享当前句和历史，展开不重置；支持长句、句末原地修正、回看与回到最新。关闭资料库不隐藏字幕窗，停止后内存资料库显示保存状态。C 的标签表示演示音源，不把麦克风 / 系统音频等同于经过识别的个人身份。

用户选择 A 的单行横条与时间线大窗，要求缩小尺寸并增加 pin，允许不置顶。修订后小窗 400×96、大窗 460×380；两种尺寸默认置顶，共享 pin 状态。取消置顶后可被资料库遮挡，重新唤回不会改变 pin 选择。该结论记录在 #15，原型继续留在独立分支；原生系统窗口行为尚未验收。

# 首次使用引导验收

2026-11-05，macOS 26.6.2、Apple Silicon。沿[首次使用与模型配置引导](https://github.com/patrick-fu/meetingtape/issues/62#issuecomment-6639222656)的选择实现 A 分步引导与 B 日常设置。

## 消费路径

`scripts/build-desktop.sh debug` 完整构建 APM、CLI 和 App，并通过 Developer ID 嵌套签名检查。验收副本使用独立应用身份、偏好及资料库、转写、录音状态和输出目录；关闭自动更新。App 与副本的未签名桌面程序、内嵌 helper 和示例音频内容一致。钥匙串配置状态沿现有服务只读查询，未更改凭据或请求云端识别。

## 实际检查

| 场景 | 观测 |
| --- | --- |
| 新资料库首次启动 | 状态加载后出现示例、权限、模型三步引导 |
| 初次状态查询失败 | 修复隔离目录权限后，后续成功查询在同一进程自动展示引导 |
| 示例体验 | 包内合成音频可以播放，按钮显示暂停；切换步骤或离开引导停止示例 |
| 准备录音 | 同步停止示例，播放和直接起录控件禁用，完成标记仍为 false |
| 权限页 | 显示当前麦克风状态；系统音频标记为首次录音时授权 |
| 模型配置 | 使用现有本地安装、云端连接和默认模型设置界面 |
| 两处编辑 | 设置窗先修改音源偏好，引导再移除一个模型；保存后两项同时保留，原设置窗清除未保存状态 |
| 稍后设置与重启 | 返回资料库，重启后沿已保存的完成状态进入资料库 |
| 重新进入 | 通用设置可重新打开引导 |
| 已有资料库 | 没有新完成标记的已有录音仍直接打开资料库 |
| 回听切换 | 播放 90 秒静音夹具后进入引导；返回时回听停止、进度归零，示例独立播放 |
| 外观 | 深浅色沿全局外观设置呈现 |

共享草稿修复前已在实际 App 复现：引导移除模型后，旧设置窗的再次保存恢复了被移除的模型。修复后两处共享同一编辑状态，使用相同操作复验保存结果。

示例音频由本机 Samantha 系统声音合成；中英字幕为对应的固定示例，体验入口不调用识别或翻译服务。

`swift test`：XCTest 3 项通过；Swift Testing 报告 65 项，其中 2 项云端 opt-in 跳过。内嵌 helper 通过现有验收器的 17 步离线检查，总报告为 `PARTIAL`，真实设备录制继续沿既有验收。

# A 全局设置窗本地验收

2026-11-02 用户选择了[独立设置窗方案 A](https://github.com/patrick-fu/meetingtape/issues/39)。原生实现见[全局设置实施票](https://github.com/patrick-fu/meetingtape/issues/40)，本记录对应开发候选，尚未包含在公开的 0.1.0 中。

## 已验证

- 在 macOS 26.6.2 中，从资料库按钮和 ⌘, 打开独立设置窗；左侧六类导航、关闭与重开、⌘W、深浅色外观均有原生操作证据。录音和转写偏好在导航、轮询及应用重启后保留。
- 实际设置窗选择 Qwen 与 MOSS、改变主稿顺序和识别模式后保存，随包 CLI 读取的模型顺序与识别模式一致。隔离库存中将已选 Qwen 标为不可用后，仍能移除它并保存为仅 MOSS；最后一项保留。
- 使用已配置凭据向豆包发送生成的一秒静音，文件转写连接测试成功；无效候选 Key 被拒绝，取消编辑后原凭据再次测试成功。测试候选通过 stdin，失败候选不会写入钥匙串。此测试只证明文件转写请求被接受，不代表实时识别、文字翻译权限或最终识别质量。
- 本地模型管理显示真实安装版本和内存推荐，目录选择面板在管理 sheet 内打开及取消正常。字幕页读取实际语言包状态，目标语言在重启后保留。本轮未重新下载模型或语言包。
- 全局“Markdown 默认附加其他版本”在重启后传入实际导出页。用十秒合成音频和标明用途的字幕夹具完成原生保存，导出字节与同一包内 CLI 在相同参数下的结果一致；不据夹具宣称录音或 ASR 质量通过。
- 更新页在启动状态加载后可以检查更新，开关直接读取和修改 Sparkle 的检查、下载偏好。未更改此前更新安装、录音忙态和正常退出的保护逻辑，也未执行新版本安装。

## 构建与检查

Swift 桌面目标编译、Developer ID 嵌套签名验证和已有本地测试通过。XCTest 3 项通过；Swift Testing 报告 64 项，其中 2 项云端 opt-in 按开关跳过，云端连接另有上述实际请求证据。独立审查发现的保存时序和不可用已选模型问题已修正并复核；多选浮层也受保存忙态保护。

本机完整构建脚本的 APM 前置环境因共享 Meson 缓存缺少 METADATA 失败。本轮复用相同基线已验收的固定 APM 静态产物，其 480 帧消费程序通过，再独立编译 CLI、桌面目标并按现有流程打包签名；音频引擎源码未改动，共享缓存修复未包含在本次变更中。

验收 App 使用独立 bundle ID、资料库、录音目录和转写目录。原用户运行实例保留，原转写设置摘要一致；未写入实际 Key。未增加 App CI、未发布新版，也不补齐既有 AEC、设备、旧系统和完整窗口矩阵缺口。

# 豆包客户端内置会议快捷操作提示词

来源：本机已安装豆包 2.34.6 的前端资源包，`static/js/async/34620.23e90a72ea.js`，配置 `settings_config.ccm_docx_ai_quick_action.actions`。

这些是客户端内置快捷操作的 `user_prompt`；本次未验证它们是否在当前运行页面启用，也未找到自动生成整篇纪要的完整服务端提示词。下文为提取原文，未经改写。

## 总结会议决策

`summary_meeting_decision`

```text
总结会议里的关键决策。要求：1. 只总结最关键的会议决策，不总结讨论过程，不总结细枝末节，不总结单纯的工作内容汇报或分享； 2. 以列表的形式总结关键决策，列表的每一项尽量控制在 60 字以内，回答直接以列表开头，不需要有铺垫的信息； 3. 务必保证结论的正确性，会议中间产生的结论可能随后被推翻，注意识别最终决策； 4. 会议结论的表述需要清晰易懂，让没参会的人也能理解，对于多主题的会议，写清楚决策是关于哪个主题的； 5. 如会中无关键决策则向用户说明，分享类会议通常无关键决策，此时简要总结会议关键内容，篇幅不要过长。
```

## 总结发言人的主要观点

`summary_speakers_content`

```text
总结会议里的发言人观点。要求：1. 只总结最主要的观点，不总结细枝末节，注意发言人的询问不算做观点；2. 对于每个发言人的观点总结，先加粗展示名字，再以列表的形式呈现每一项观点，注意表达精简；3. 不需要有任何铺垫信息，直接输出总结；4. 请勿对未发言的用户做总结；5. 不需要输出辅助信息；6. 参考智能纪要或文字记录文档作答
```

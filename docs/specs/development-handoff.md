2026-10-29。来源为[决策地图](https://github.com/patrick-fu/meetingtape/issues/18)及用户逐轮确认。生产基线 `df5bcdd`，已有引擎、GUI、录后与实时字幕草稿栈保留。核心产品规则已清楚，沿用户此前持续推进开发的授权进入隔离开发；此文不是功能完成报告。

## 目标与数据形态

一段录音保留一个双声道原文件。识别结果按录音、阶段、任务/版本、模型和音源归属；每个音源执行有自己的重试、云请求与观测，不共用另一条的进度。实时语句存在临时修订与定稿，译文必须关联具体语句修订和目标语言。

默认对已确认的 MeetingTape 双路录音分开识别，设置允许合并；模式在新录音/新任务开始时冻结。保留旧混音稿的真实含义。任意外部音频原有入口不能因新默认被破坏，也不能仅凭 stereo 伪造系统/麦克风来源；显式要求 split 而无有效映射时应清楚报错。重试不重新解析偏好，去重需计入冻结模式。

## 实现前已知风险

- 当前任务、云请求及 partial 文件按模型唯一，需要先拆开音源执行身份。仅给正文加 source 不能隔离失败与重试。
- 当前实时 ID 使用开始时间，而既有夹具中 partial/final 开始时间会变化。异步翻译不能只按时间或旧 ID 粘贴。
- 重新开启的起点不能用落后于当前录音时钟的 committedSeconds，否则会补传关闭期间积压。
- 覆盖必须独立于正文保存，旧 archive 未记录的信息不得倒推。
- 新 Codable 字段必须显式兼容缺失键；App/CLI 需能取得部分/失败结果，导出器不猜磁盘布局。
- 当前 `--timestamp=none` 仅适用于既有本地路径，发行前需安全时间戳；TCC、helper 与资源完整性仍需实机证据。

## 边界与验收纪律

本地编译与验收，不新增 CI。保留用户当前 App、录音、保存目录和既有结果；实验使用独立状态目录及合成内容。用户样本只读，不写入公开材料。不切换宿主机网络。丢录音、破坏原稿、时间轴/导出错误、敏感泄漏阻断发布。

本地翻译候选、已安装语言包与实际延迟用隔离实验决定，不把当前实时 ASR 误称为离线。原有 AEC FAIL、长时、设备和跨 Space/全屏缺口按已确认预发布政策披露；稳定版前补齐。公开/历史重写前先形成具体清理和迁移证据，不把 filter 成功或公证 Accepted 当作最终成功。
